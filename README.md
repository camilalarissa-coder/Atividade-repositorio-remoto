# Atividade para criar um repositório remoto

Projeto desenvolvido para praticar conceitos básicos de Node.js e JavaScript.

## O que foi feito:

- Foi criada a estrutura básica de um projeto Node.js.
- Foram adicionados exemplos de variáveis usando `const` e `let`.
- Foi criado um exemplo de função.
- Foi utilizado o `console.log()` para mostrar os resultados no terminal.
